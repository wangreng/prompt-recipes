# 迁移需求：多 Bot 协作 Agent 产品官网（中文）

**产品：** 「工位」（暂名），一个 Bot 化的个人 Agent：你雇一组各有分工的 Bot（例如 调研 Bot、写作 Bot、日程 Bot、代码 Bot、盯盘 Bot），在一个群里给它们派活，它们互相交接、各自汇报，你只看结果和审批关键一步。

**目标用户：** 独立开发者、产品经理、小团队负责人。

**页面必须有：**
1. 首屏：一句话说明 + 主按钮「申请内测」+ 次按钮「看演示」；一个能表达「多个 Bot 同时在干活」的画面（例如一个群聊/任务面板示意）。
2. Bot 阵容：至少 5 个 Bot 卡片，每个有名字、职责一句话、状态（工作中/空闲/等你审批）。
3. 工作方式：派活 → Bot 分工并互相交接 → 你审批关键一步 → 汇总交付，4 步。
4. 一个可交互演示：点击「派一个任务」按钮，页面上依次出现几条 Bot 的消息/状态变化（脚本模拟即可）。
5. 安全与控制：至少 3 点（权限分级、关键操作需审批、全程留痕可回看）。
6. 价格或内测说明 + 页脚。

**可交互状态：** 按钮 hover；演示的「未开始/进行中/完成」三种状态；Bot 卡片 hover。

**视口：** 桌面 1440 宽为主，手机 390 宽不能乱。

**素材限制：** 不能用真实品牌 logo；Bot 头像用 CSS/SVG/emoji 画，不用外部图片链接。

**验收：** 6 个区块都在、中文文案讲的是本产品；演示能真的一步步跑；首屏 3 秒内看懂“多个 Bot 帮你干活”。
