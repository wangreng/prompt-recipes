# Product Brief: Memoh

## Product Overview
**Memoh** is a cloud-first multi-agent software platform in which every AI assistant runs inside its own dedicated, continuously available virtual computer complete with a graphical desktop, persistent filesystem, and network access.

- **Target Audience:** Developers, builders, and technically minded individuals or small teams seeking autonomous AI assistants that run around the clock in the cloud, operate real desktop software and browsers, preserve long-term context across conversations, and remain reachable from everyday messaging apps.
- **Tone & Positioning:** Calm, capable, direct, and developer-credible. Focuses on concrete computing utility, continuous reliability, and human-in-the-loop control rather than promotional hype.

## Page Sections & Content Plan

### 1. Hero Banner & Interactive Workspace Preview
- **Artwork:** A wide, painterly sunset-to-dusk landscape showing snow-capped peaks beneath deep blue upper skies and luminous peach-and-coral clouds, a calm reflective river, a sleek passenger train crossing a stone viaduct toward a glowing city skyline, and a dark cat silhouetted on a wildflower hillside looking out over the water.
- **Messaging:**
  - Opening headline introducing the core promise: equipping an AI agent with its own persistent cloud computer.
  - Concise two-line explanation stating that Memoh hosts multiple agents in the cloud, each equipped with a dedicated desktop environment, file storage, and always-on networking.
- **Actions:**
  - Primary launch action sending users to the web application.
  - Secondary OS-aware desktop download split-button offering the detected desktop installer (such as Linux) alongside a dropdown menu for choosing alternative operating systems and builds.
- **Focal Showcase:** Overlapping the dark bottom fade of the hero is a large interactive desktop-application preview framed like a dark-mode native window, showing a workspace navigation sidebar (chat, files, schedule, packages, search, quick actions, folders) alongside an active conversation demonstrating memory retrieval and inline tool execution.

### 2. Core Capability Showcase (Dedicated Virtual Computer)
- **Section Intro:** Centered heading and brief overview underscoring that every agent operates continuously on an actual virtual computer with its own desktop, files, and network.
- **Four Workflow Vignettes** (each pairing a concise title and two-sentence explanation with a playable and pausable animated miniature desktop window):
  1. **Third-Party Agent & Model Compatibility:** Explains deploying external coding or ACP-compatible agents (such as Codex or Claude Code) onto a Memoh cloud machine, using either personal subscriptions or platform-supplied models. *Demo:* New session composer switching between models and agent backends.
  2. **Autonomous Desktop Operation with Human Handover:** Explains letting an agent operate desktop apps and browse websites on its virtual screen while the user observes live or takes manual control at any moment. *Demo:* Split-pane workspace showing a chat panel beside a live Linux desktop running Chromium.
  3. **Centralized Package, Connector & Skill Hub:** Explains single-click management of runtime dependencies, third-party app connectors, and agent skills hosted directly on the cloud computer. *Demo:* Workspace sidebar displaying an internal package catalog with installed tools (Claude Code, Codex, Node.js) and installable developer utilities (such as `uv`).
  4. **In-Cloud Development & Live App Preview:** Explains writing code and running development servers entirely inside the cloud environment, then inspecting the live application inside an adjacent workspace tab. *Demo:* Agent building a small web tracker and launching its local preview in a new tab.

### 3. Always-On Autonomy Strip (Three Proof Cards)
- **Section Intro:** Centered heading and short contrast between a sleeping personal laptop and a continuously running cloud agent that stays active and alerts the user when needed.
- **Three Cards** (each containing a concise title, one-line explanation, and a tall portrait dark-mode UI proof):
  1. **Scheduled Background Execution:** Automated recurring tasks and periodic check-ins that run without manual intervention. *Proof UI:* Grouped schedule view organized by day showing recurring routines (such as inbox organization, morning summaries, and release tracking) with execution times, recurrence labels, and active/inactive toggles.
  2. **Proactive Outbound Notifications:** The agent reaches out first whenever a tracked event or deadline requires attention. *Proof UI:* Dark-mode messaging thread where a user asks to monitor a software release and later receives proactive follow-up alerts when it ships and ahead of a scheduled review.
  3. **Persistent Cross-Session Memory:** Conversations maintain continuity rather than resetting between sessions. *Proof UI:* Chat exchange showing a user asking about an earlier pull request, an inline memory-lookup step, a grounded answer, and a request to record key takeaways into a persistent markdown memory file.

### 4. Omnichannel Access Strip

  1. Native desktop client
  2. Telegram (showing online status)
  3. WeChat (minimal dark chat header)
  4. Discord (channel view)
- **Additional Integrations Row:** Short centered label indicating additional platform support, followed by uniform dark icon tiles for Telegram, Discord, Slack, WeChat, Lark, QQ, and LINE.

### 5. Pricing Tiers
- **Section Intro:** Simple centered pricing heading.
- **Three Monthly Subscription Cards** (each highlighting core compute allocations at the top of a checkmark list, secondary inclusions beneath, and a full-width sign-up action at the bottom):
  1. **Go (Highlighted with a recommended badge):** Entry tier for everyday conversations and light tasks at **$5 per month** — 8 total CPU cores, 16 GB total RAM, 2,500 monthly token credits, 40 GB persistent volume storage (excluding root filesystem), up to 1 member, unlimited bots, and access to multiple model families (DeepSeek, Kimi, GPT, Claude, and others).
  2. **Pro:** Mid-tier plan for daily productivity and always-ready workflows at **$60 per month** — 16 total CPU cores, 32 GB total RAM, 30,000 monthly token credits, 120 GB persistent volume storage, up to 3 members, plus everything included in Go.
  3. **Premium:** High-capacity tier for demanding compute workloads and larger groups at **$150 per month** — 32 total CPU cores, 64 GB total RAM, 75,000 monthly token credits, 300 GB persistent volume storage, up to 8 members, plus everything included in Pro.
