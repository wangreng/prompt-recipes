# mapkit-official

Two independent official sites for handdrawn-map-kit (read-only dependency), one by agy (Gemini 4 Neon high), one by Codex (GPT-6-Astra), same BRIEF.md.

To rebuild: in agy/ or codex/, clone the kit into ./kit (git clone https://github.com/wangreng/handdrawn-map-kit kit && (cd kit && npm ci)), then run ./build.sh. Open site/index.html.
