Declarative YAML / JSON → Dry-Media Raster Maps

Hand-drawn cultural maps, authored by AI agents.

handdrawn-map-kit is a Node.js engine inspired by Aleksandra & Daniel Mizielinski’s Maps (《地图（人文版）》). It renders paper tooth, technical pen, colored pencil, sumi brush, and watercolor wash from declarative specs — with just two runtime dependencies (@napi-rs/canvas, js-yaml).

LIVE SELF-BUILD This page is rendered by the kit itself. Rebuild it end to end: 
./build.sh

Runs npx handdrawn-map render on specs/site-desktop.yaml, specs/site-mobile.yaml, and all 4 --style plates of examples/specs/italy.yaml, then writes site/.

I

Natural Earth Geography

Bundled data/ packs 242 countries (1:50m), 4,589 admin-1 states & provinces across 251 countries (zh & ISO-3166-2), 1,251 populated places (zh/ja/ko & capitals), 461 rivers, 412 lakes, and 81 peaks / 259 landform regions. Reference real features by name instead of hallucinating coordinates.

II

65 Built-in Icons & Characters

43 classic East Asian & cartographic illustrations plus 22 China, Europe, and world landmarks (panda, greatWall, cathedral, windmill, romanArch, vineyard, hotAirBalloon, yurt…), 34 waving flags, and 10 parameterized person poses — each reporting exact mm ELEMENT_BOUNDS.

III

Inline SVG Dry-Media Renderer

Zero-dependency src/svgDraw.js parses <path d>, basic shapes, transform, and style inheritance, rasterizing custom landmarks through the pencil, watercolor wash, and hatching engine. Persist reusables locally via --save-assets or handdrawn-map assets save.

IV

CJK & Bilingual Typography

Ships Hershey-derived Kevin Serif / Kevin Sans alongside bundled ZCOOL XiaoWei (SIL OFL 1.1), OS CJK discovery, and registerFont(). Supports mixed Latin/Han/Kana/Hangul metrics, stacked/inline writeBilingual, curved writeAlongPath sea labels, and CJK-safe cartouches.

V

Auto-Layout & Diagnostics JSON

Spatial OccupancyGrid auto-places placement: auto cartouches & compasses in open sea (with landlocked fallback), resolves overlaps by priority (--auto-layout), routes curved callouts, and emits mm bounding-box diagnostics via --diagnostics.

VI

Four One-Flag Visual Presets

Switch paper stock, stroke tool (fineliner, gel, brush), fill pipeline (pencil, wash, washBloom), coastal waterlines, compass, cartouche, and neatline border in one flag: vintage-atlas, blueprint, nocturne, or ink-wash.

  1. 01 · INSPECT

    Query real data

    Run inspect countries, admin1, places, rivers, elements, styles --json, plus zero-raster inspect spec map.yaml --json.

  2. 02 · AUTHOR SPEC

    Write YAML / JSON

    Draft a schemaVersion: 1 spec using geo.fit, auto Natural Earth layers, built-in icons, inline type: svg landmarks, and placement: auto chrome.

  3. 03 · RENDER + DIAG

    Inspect layout JSON

    Render fast 5 ppm previews with --fast --auto-layout --diagnostics - (pure JSON to stdout, summary to stderr) and read overlapCount & emptyRegions.

  4. 04 · FIX + HD

    Converge & export

    Adjust colliding fixed: true items or priorities until overlaps and OOB hit 0, then render the final plate at 10 ppm with --hd (up to 18.5 MP cap).

Declarative Spec (schemaVersion: 1) YAML / JSON 
schemaVersion: 1
meta: { id: sichuan-cultural, lang: zh, seed: sichuan-1 }
canvas: { w: 300, h: 200, ppm: 10, border: true }
style:  { preset: vintage-atlas }
geo:
  fit:    { target: { country: China, admin1: Sichuan }, margin: 12 }
  admin1: { country: China, highlight: [Sichuan] }
layers:
  graticule: true
  rivers:    { auto: true, maxRank: 6 }
  mountains: { auto: true, scale: 0.85 }
elements:
  - { id: el-panda, type: panda, lon: 103.42, lat: 31.15 }
  - { id: el-mask,  type: svg,   lon: 104.22, lat: 31.00, svg: "<svg...>" }
compass:   { placement: auto, r: 7.5 }
cartouche: { placement: auto, w: 78, h: 42, country: 四川省, flag: CHN }
layout:    { autoPlace: true, avoidOverlap: true, padding: 1.5 }

CLI Quick Start Node >= 20 
# Install from GitHub
npm install github:wangreng/handdrawn-map-kit

# Inspect real Natural Earth data & built-in assets
npx handdrawn-map inspect admin1 China --json
npx handdrawn-map inspect elements --json

# Render declarative spec with auto-layout & diagnostics
npx handdrawn-map render examples/specs/sichuan.yaml \
  -o out/sichuan.png --fast --auto-layout --diagnostics out/sichuan.diag.json

# Switch style or export final 3000×2000 px HD plate
npx handdrawn-map render examples/specs/italy.yaml --style ink-wash --hd
Programmatic JS API CommonJS 
const { createMap } = require('handdrawn-map-kit');

const map = createMap({ w: 300, h: 200, seed: 'italy-01' });
const proj = map.fitProjection('Italy');
map.graticule(proj);
map.countries(proj, { focus: 'Italy' });
map.admin1(proj, { country: 'Italy', bordersOnly: true });
map.geoRivers(proj, { maxRank: 6 });
map.geoLakes(proj);

const [x, y] = proj(12.496, 41.902);
map.city(x, y, 'Roma', { capital: true });
map.cartouche(13.5, 13, 88, 44, { country: 'ITALIA', flag: 'ITA', capital: 'Roma' });
await map.save('out/italy.png');
