II
AUTHORING GUIDE   /   02

The agent workflow

The bundled SKILL.md describes the schema and the render-and-refine loop.

  1. Inspect the kit

    Query places, elements, and styles with the CLI.

  2. Draft the spec

    Describe geography, layers, labels, and illustrations in YAML or JSON.

  3. Render a proof

    Use --fast --auto-layout --diagnostics - for a preview and structured JSON.

  4. Refine the plate

    Check overlaps and out-of-bounds items, adjust the spec, and repeat. Finish with --hd.

III
AT THE TERMINAL   /   03

Quick start

From this project folder, inspect the illustration library and render the Japan spec.

cd kit
npx handdrawn-map inspect elements
npx handdrawn-map render ../specs/japan.yaml \
  --fast -o ../japan.png
