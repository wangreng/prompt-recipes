Three steps from YAML to watercolor · 怎么用

Describe geography and cultural icons once, render through the Node.js CLI, and inspect either the finished map or structured JSON diagnostics.

01

Declare a YAML spec

Geography, watercolor palette, ornaments & sprites.

japan.yaml 
title: "JAPAN"
subtitle: "Nippon · Archipelago of East Asia"
region:
  country: JPN
  layers: [coast, provinces, rivers, peaks]
style:
  medium: watercolor-pencil
  border: zebra
  compass: bottom-right
  font: ZCOOL XiaoWei
illustrations:
  - { sprite: mt-fuji,    at: [138.73, 35.36] }
  - { sprite: shiba-inu,  at: [139.69, 35.68] }
  - { sprite: torii-gate, at: [132.32, 34.30] }
  - { sprite: ramen-bowl, at: [141.35, 43.06] }
02

Render with one CLI call

Run directly or emit diagnostics JSON for an agent loop.

$ npx handdrawn-map-kit render japan.yaml -o japan.png --scale 2x
✓ Natural Earth vectors loaded (JPN + Ryukyu) ✓ 24/24 sprites placed · 0 label overlaps ✓ Watercolor wash & zebra border inked → japan_cultural_map.png (1500×1000, 1.6 MB)

Colophon, credits & licenses · 致谢与许可

Rendering engine

Derived from statechart-art, adapted for cartographic watercolor rendering and layout diagnostics. Released under the MIT License.

Typography & lettering

CJK cultural map lettering uses ZCOOL XiaoWei (站酷小薇体) under the SIL OFL. Documentation set in Caveat, DM Sans & Geist Mono.

Geography & inspiration

Base vector geography courtesy of public-domain Natural Earth. Editorial spirit inspired by Aleksandra & Daniel Mizieliński’s Maps (《地图（人文版）》).
