02 · Quick start

From YAML spec to print in three steps

Describe the geography and cultural pins once, run one Node.js CLI command, and inspect the rendered map alongside structured layout diagnostics.

01

Write a map spec

Declare region, ornaments, CJK lettering & pins.

title: "JAPAN"
subtitle: "Archipelago of East Asia"
region:
  country: JPN
  layers: [coast, rivers, peaks]
ornaments:
  border: zebra
  compass: bottom-right
typography:
  font: "ZCOOL XiaoWei"
  autoAvoid: true
pins:
  - icon: mt_fuji
    at: [138.73, 35.36]
    label: "Mt. Fuji · 富士山"
  - icon: pagoda
    at: [135.76, 35.01]
    label: "Kyoto"
02

Run the CLI renderer

One command draws pencil ink, washes & emits JSON.

npx handdrawn-map-kit render japan.yaml \
  --out japan_cultural_map.png \
  --diagnostics report.json
report.json 0 overlaps · ready 
{
  "canvas": "1500x1000",
  "placedPins": 24,
  "labelCollisions": 0,
  "nudgedLabels": 5,
  "densityScore": 0.64,
  "status": "clean"
}

03 · What’s inside the kit

Six handmade tools on one paper desk

Everything an indie builder, educator, or AI agent needs to turn structured geography into a warm storybook atlas.

yaml / json · node cli

Declarative spec & CLI

Define regions, rail routes, pins, and watercolor palettes in version-controlled YAML or JSON—render crisp maps in a single Node.js command.

natural earth · offline

Built-in Natural Earth data

Ships with ready-to-project geographic layers—countries, provinces, rivers, lakes, cities, and mountain peaks—no external tile API required.

65 glyphs · cultural pack

65 hand-drawn illustrations

Drop in pandas, the Great Wall, dumplings, pagodas, windmills, ships, and regional landmarks drawn with chunky pastel texture and expressive outlines.

cjk · zcool xiaowei

CJK handwritten typography

First-class Chinese, Japanese, and Korean hand-lettered typesetting (中 / 日 / 韩) paired with curved ocean labels and vintage serif titles.

auto-avoid · ornaments

Auto-layout & vintage ornaments

Collision avoidance automatically resolves overlapping pins and leader lines, framed by zebra borders, compass roses, and banner title cartouches.

agent skill · report.json

Agent Skill + diagnostic JSON

Includes a ready-to-use Agent Skill so AI agents can draft specs, render maps, inspect structured overlap/density JSON, and self-correct iteratively.
