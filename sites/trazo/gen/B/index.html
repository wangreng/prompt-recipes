how it works · 三步出图

Three steps from YAML to watercolor

Write a readable YAML description by hand—or let your AI agent draft and refine it using structured layout diagnostics.

01

Declare the map in YAML

Pick a Natural Earth region, drop cultural motifs by city, and turn on vintage ornaments.

japan.yaml 
title: "JAPAN"
subtitle: "Nippon · Archipelago"
region:
  country: Japan
  inset: Okinawa
style: pencil-watercolor
font: ZCOOL XiaoWei
layers: [coast, rivers, peaks, rail]
ornaments: [zebra, compass, banner]
motifs:
  - { id: mt-fuji, near: Tokyo }
  - { id: torii-gate, near: Hiroshima }
  - { id: ramen-bowl, near: Sapporo }
  - { id: pacific-whale, sea: Pacific }
02

Run one CLI command

Render high-DPI PNG or SVG locally, plus diagnostic JSON for agent self-review.

# Render map + layout diagnostics
npx handdrawn-map-kit render \
  japan.yaml \
  --out japan_cultural_map.png \
  --diagnostics diag.json
collisions: 0 motifs: 24/24 render: 1.4s
