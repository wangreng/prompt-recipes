02 / Quick Start · 三步出图

YAML spec → CLI render → Atlas plate

Describe geography, cultural motifs, and vintage ornaments in one readable file. Run a single Node.js command to render the map and emit layout diagnostics your AI agent can inspect.

  1. 01

    Declare a YAML spec

    Select a region from bundled Natural Earth vectors, pick a watercolor style, place hand-drawn motifs by coordinates, and enable vintage cartographic ornaments.

    Supports YAML & JSON schemas
    japan.yaml YAML 
    title: "JAPAN"
subtitle: "Nippon · Archipelago of East Asia"
canvas: { width: 1500, height: 1000, style: "watercolor-fineliner" }
region:
  country: "JPN"
  layers: ["coastline", "rivers", "peaks", "cities"]
  inset: { label: "RYUKYU / OKINAWA", bounds: [123.5, 24.0, 131.0, 29.0] }
ornaments: { border: "zebra", compass: "bottom-right", cartouche: "flag-box" }
typography: { cjkFont: "ZCOOL XiaoWei", avoidCollisions: true }
motifs:
  - { id: "mt-fuji",       at: [138.73, 35.36], label: "Mt. Fuji" }
  - { id: "torii-gate",    at: [132.32, 34.30], label: "Miyajima" }
  - { id: "ramen-bowl",    at: [141.35, 43.06], label: "Sapporo Ramen" }
  - { id: "pacific-whale", at: [144.80, 38.90], label: "Pacific Whale" }
  2. 02

    Run one CLI command

    Render high-resolution PNG artwork headlessly in Node.js with automatic label repulsion, leader lines, and an optional JSON diagnostic report for AI agents.

    Requires Node.js 18+ · No browser needed
    terminal SHELL 
    # Install globally or invoke directly with npx
npx handdrawn-map-kit render japan.yaml \
  --out japan_cultural_map.png \
  --diagnostics diagnostics.json
  3. 03

    Get artwork & diagnostics

    Out comes a publication-ready cultural map plus structured collision & coverage telemetry so an AI agent can verify legibility and refine placements autonomously.

    Closed loop with bundled Agent Skill
    diagnostics.json JSON 
    {
  "status": "ok",
  "labelsPlaced": 28,
  "motifsPlaced": 22,
  "overlaps": 0,
  "leaderLines": 5,
  "inkCoverage": 0.34,
  "suggestions": []
}
03 / Capabilities · 核心特性

Crafted for illustrated clarity & agent automation

Traditional GIS tools look clinical; pure diffusion images hallucinate borders and text. handdrawn-map-kit pairs real cartographic vectors with tactile watercolor rendering.

Declarative Spec & CLI

声明式规格 + CLI

Author maps in version-controlled YAML or JSON and render deterministically from Node.js — ideal for CI pipelines, educational books, and travel editorial workflows.

Built-in Natural Earth Data

内置地理矢量数据

Ships with bundled Natural Earth vectors — countries, provinces, rivers, lakes, major cities, and mountain peaks — with zero shapefile hunting or map server setup.

65 Hand-Drawn Cultural Motifs

65 个手绘插图元素

A curated library of fineliner-and-watercolor stamps: pandas, the Great Wall, dumplings, windmills, torii gates, whales, ramen bowls, ships, wildlife, and local landmarks.

CJK Handwritten Typography

中日韩手写体排版

Crisp multi-script map labeling with ZCOOL XiaoWei and paired editorial serifs so Chinese, Japanese, Korean, and Latin place names feel naturally hand-lettered.

Auto Layout & Avoidance

自动布局避让

Built-in collision detection nudges crowded coastal labels, routes dashed leader lines cleanly over open water, and frames distant archipelagos in neat inset boxes.

Agent Skill + Diagnostic JSON

Agent Skill + 诊断 JSON

Ships with a ready-to-install Agent Skill and structured JSON diagnostics (overlaps, bounds, density) so AI agents draw maps, read feedback, and iterate without human intervention.
