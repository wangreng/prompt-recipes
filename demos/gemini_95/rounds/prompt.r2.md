Build a nostalgic Windows 95 desktop simulator called "Gemini 95" with classic 90s apps reimagined by Gemini AI.

Start on a full-screen classic Windows 95 teal desktop with no scrollbars or open windows. Near the top-left, place seven icons in one evenly spaced horizontal row spanning roughly the left two-thirds of the screen (wide spacing, ~100px columns). Use crisp Win95-style outlined vector icons—not chunky pixel art—above clean small white Inter labels with only a faint shadow.

Fix a light-gray bottom taskbar with a white top edge, keeping the right side completely bare (no system tray, clock, volume icon, or dividers). On the far left, place a raised 3D beveled Start button with a stylized blue-to-purple gradient "Gemini" wordmark, dark outline, and cyan-blue sparkle on top (no Windows flag or plain black text). It toggles a Start menu of all seven apps (navy-blue hover); open apps appear as beveled buttons pressed when active.

Give windows light-gray chrome, 3D beveled borders, navy-blue title bars with bold white titles, sunken content areas, and beveled minimize/close buttons. Use Inter for OS UI, Courier New for Notepad/counters, Times New Roman for browser controls, and Comic Sans for AI quips. Single-clicking icons or Start items opens/restores draggable, resizable windows that focus on click and toggle from the taskbar.
